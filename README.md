# Horizontal Image Gallery

A responsive and interactive horizontal image gallery built using HTML, CSS, and JavaScript. The gallery allows users to navigate images smoothly using mouse wheel scrolling and previous/next buttons. It provides a clean UI with seamless horizontal scrolling behavior for an enhanced browsing experience.

## Features

* Smooth horizontal scrolling
* Mouse wheel support for side scrolling
* Previous and next navigation buttons
* Responsive design
* Simple and lightweight implementation
* Easy to customize and integrate

## Technologies Used

* HTML
* CSS
* JavaScript

## How It Works

* Scrolling the mouse wheel moves the gallery horizontally.
* Clicking the next button scrolls images forward.
* Clicking the back button scrolls images backward.
* Smooth scrolling is enabled for button navigation.
